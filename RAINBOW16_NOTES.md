\# Rainbow16-Orca development notes



This repository is a fork of OrcaSlicer prepared for experimental Rainbow16 support.



Current confirmed plan:

\- Keep Snapmaker U1 as Snapmaker U1.

\- Do not globally pretend that Snapmaker U1 is a Bambu/BBL printer.

\- Add Rainbow16 as an optional mode.

\- When Rainbow16 is disabled, OrcaSlicer should behave normally.

\- When Rainbow16 is enabled, Snapmaker U1 should support 16 logical colors mapped to 4 physical U1 toolheads and Rainbow16 lanes.

\- AMS mapping logic can be used only as a reference.

\- Function, class and setting names used in planning notes are only examples. Final names must match existing OrcaSlicer naming style and already implemented Rainbow16 project code.
